# MarketMind
## Explainable Stock Market Intelligence & What-If Prediction Platform

> **Academic & Educational Disclaimer**  
> MarketMind is an educational and research-oriented analytics platform designed to demonstrate principles in Mathematics/Statistics, Machine Learning, Data Visualization, and Software Engineering. Predictions, probabilities, risk indicators, and what-if scenarios are generated by statistical and machine-learning models and are subject to uncertainty. They are not guaranteed outcomes, investment recommendations, or personalized financial advice.

---

## 🌟 Overview & Philosophy

MarketMind is an end-to-end full-stack intelligence platform that shifts the focus away from black-box "stock price predictors" toward **probabilistic market direction analysis**, **interpretable feature attribution (SHAP)**, **leakage-free walk-forward backtesting**, and **controlled what-if scenario simulations**.

### Core Academic Integrations
1. **Mathematics, Probability & Statistics**: Descriptive statistics, log returns, empirical return distributions, normal curve fitting, Value-at-Risk (VaR), Pearson/Spearman correlation matrices, two-sample hypothesis testing ($H_0/H_1$, p-values, test statistics).
2. **Machine Learning**: Directional classification (Logistic Regression, Linear/RBF SVM, Decision Trees, Random Forest Ensembles), Return regression, Unsupervised Market Regime Clustering (K-Means), Dimensionality Reduction (PCA), and Model Baselines.
3. **Explainable AI**: Global feature importance rankings, Local SHAP waterfall and force attributions, and Partial Dependence curves.
4. **Data Visualization**: Dark-mode financial user interface with responsive Candlestick charts, Return histograms, Boxplots, Correlation heatmaps, Walk-forward error distributions, and What-If comparative sensitivity cards.
5. **Software Engineering**: Modular layered architecture, strict schema validation via Pydantic v2, database ORM with SQLAlchemy 2, automated unit, ML leakage, and integration test suites.

## 🚀 Getting Started

### Prerequisites
- Python 3.11+
- Node.js 18+ and npm
- (Optional) Docker & Docker Compose

### 1. Backend Setup
```bash
cd backend
python -m venv venv
# On Windows:
.\venv\Scripts\activate
# On Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
cp ../.env.example .env
uvicorn app.main:app --reload --port 8000
```
API Documentation will be available at: `http://localhost:8000/docs`

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
Dashboard will be available at: `http://localhost:5173`

### 3. Running with Docker Compose
```bash
docker-compose up --build
```

## 🧪 Testing

MarketMind includes dedicated test suites for statistical calculations, feature pipelines, API endpoints, and critical **ML Data Leakage Prevention**:

```bash
cd backend
pytest -v
```

To run data leakage tests specifically:
```bash
pytest tests/test_data_leakage.py -v
```
